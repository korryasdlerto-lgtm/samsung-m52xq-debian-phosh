# Unofficial v1 (первый публичный релиз)

Для кого: пользователи порта и разработчики, которым нужно знать, что вошло в первый публичный релиз Debian (Mobian) +
Phosh для Samsung Galaxy M52 5G и почему.

| | |
|---|---|
| Ядро | 7.1.13, та же сборка, что в порте postmarketOS Phosh: переключение устройства q6voice на месте, сон панели при яркости 0, энергосбережение ath11k при выключенном радио, исправление чтения GPI на общем SE, QP/битрейт Venus HFI 6xx (`kernel/patches/`) |
| Дерево устройств | DTB из `sm7325-samsung-m52xq.dts` (стиль апстрима) + локальные узлы, включён RTC; `snd_usb_audio.index=-2` (`device-tree/`) |
| Корень | Debian forky arm64 + Mobian, systemd, Phosh 0.58, 1039 пакетов ([packages-debian.txt](packages-debian.txt)), 33 наших на удержании |
| Образ | чистый: без личных данных, ключей и закрытых прошивок, ext4 3420 МиБ, 2 чанка |
| Zip | `debian-mobian-phosh-m52xq-mainline-v1.zip` (1,05 ГБ), md5 `7494cc8cb04a9db69ed78072a39d2712` |

Нужна чистая установка: Format Data, как описано в README.

## Установщик и образ

- **В zip нет закрытых прошивок.** ADSP, модем, IPA, Venus, zap-шейдер GPU, прошивка Bluetooth, конфиги и реестр датчиков
  копируются при установке с разделов самого телефона.
- Установщик увеличивает `system` до 8 ГБ, до записи проверяет, что образ помещается, пишет boot, vendor_boot и dtbo.
- `/home` на разделе userdata (`m52xq-home-on-userdata`): около 100 ГБ под фото и видео.
- Ключи SSH и machine-id создаются при первой загрузке; адрес Bluetooth читается из EFS.
- В `/etc/fstab` есть строка `proc`: с пустым fstab initramfs pmOS ждал раздел boot и останавливался в отладочной консоли.

## Звонки, SMS, мобильные данные

- **Две SIM (DSDS)** в ModemManager (патчи 0100–0106): обе активны, второй объект модема для SIM 2, SIM для данных,
  «SIM 1 / SIM 2» в Phosh, Calls и Chatty, плитка пустого слота скрыта; приложение «SIM cards manager».
- **GNOME Calls:** удержание, «Добавить вызов» на той же SIM, второй вызов, Swap, SIM в истории, окно вызова выходит на
  передний план, звонок не кладётся при скрытии окна, экран вызова в альбоме и **набор номера в альбоме**.
- Разговорный динамик, громкая связь, USB- и Bluetooth-гарнитуры; экран гаснет у уха; удержание и новый вызов на экране блокировки.
- Мобильные данные: ручное подключение «Mobile data» (APN `internet`, IPv4) для плитки Phosh.

## Telegram

- Telegram Desktop со **звонками**: звук в разговорный динамик (кнопка «Громкая связь» переключает), микрофон без помех
  (PipeWire открывает и микрофон в S16LE), экран гаснет у уха, входящий во сне включает экран и звонит
  (`m52xq-tg-stream`, `m52xq-voip-audio`, `m52xq-audio-route`, `m52xq-speakerphone`).
- Звонок больше не сбрасывается при разблокировке: Telegram запускается с `GIO_USE_NETWORK_MONITOR=netlink` (монитор GLib через
  NetworkManager сообщал «сеть изменилась», когда после пробуждения возвращались режимы модема).
- Звуки сообщений: установлен `libcanberra-pulse` (без него Phosh/feedbackd молчали).
- Камера в Telegram через виртуальные веб-камеры (`m52xq-virtualcam`, libcamera → v4l2loopback).

## Камера (GNOME Snapshot)

- libcamera 0.8.0 с нашими патчами, PipeWire пересобран под неё, Snapshot с патчем камеры из порта postmarketOS.
- Все четыре камеры: основная 64 Мп, фронтальная 32 Мп, широкая, макро; кадры поворачиваются по экрану; фото широкой и
  макро больше не сохраняются на боку.
- **Фото 64 / 32 Мп** через `m52xq-rawphoto` (raw-съёмка, проявка на GPU); фокус касанием, зум.
- **Видео на аппаратном кодере (Venus)**: 1080p и 4K, нормальный битрейт после исправления Venus в ядре.

## Сон и питание

- NetworkManager не реагирует на сигнал сна logind (патч `network-manager` + файл-флаг): приложения не видят обрыва сети при
  каждом сне, телефон больше не просыпается каждые 15 с с открытым Telegram (доля сна около 45 % → 75–83 %).
- s2idle с «тёмным пробуждением»: пробуждения по сети не включают экран; будят звонки, SMS и будильник (RTC).
- Яркость не остаётся почти чёрной после перезагрузки с притушенного экрана (`m52xq-backlight-min`).
- Своё засыпание по бездействию (`m52xq-idle-suspend`) узнаёт звонки Telegram и восстанавливается после перезапуска PipeWire.

## Прочее

- Phosh: автоповорот сам восстанавливается после загрузки; Mobile Settings сохраняет переключатели Bluetooth / Wi-Fi.
- Приложение «Reboot menu» с пунктом «Reboot into recovery».
- USB-гарнитура, вставленная при загрузке, больше не занимает звуковую карту 0.

## Исправления последних сборок

- **ModemManager больше не падает при засыпании с включёнными мобильными данными** (патч 0107, перенос из ModemManager 1.25):
  данные этого модема идут только мультиплексными подключениями (IPA/rmnet), а 1.24 сравнивал их число с максимумом обычных (0).
  ModemManager перезапускался уже во сне, и входящие звонки в этот сон терялись. Проверено: 248 засыпаний с данными, звонок во сне звонит.
- **Камера, оставленная открытой, больше не держит телефон без сна всю ночь:** Snapshot запрещает простой сеанса, пока открыто его окно;
  теперь при блокировке экрана он закрывается (если не идёт запись видео), и телефон засыпает.
- **Плитки шторки:** «NFC» (rfkill, состояние сохраняется после перезагрузки) и «Громкая связь» (вместо приложения «Громкая связь»).
- SIM cards manager при одной вставленной SIM показывает действующий режим.

## Известные проблемы

См. README: датчики отваливаются после многих часов снов (FastRPC), изредка падает прошивка Wi-Fi при пробуждении, в долгом
сне Wi-Fi может не разбудить телефон, около 2,5 %/ч во сне с Telegram (аудио-DSP пока не спит), качество камеры при слабом
свете, 4K на высоком битрейте около 20 кадров/с.
